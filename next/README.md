# 서울중앙교회 예배위원회 운영 대시보드

예배위원회의 1년 살림(연간 일정 · 위원장 체크리스트 · 예산 집행 · 거래처 · 팀 명단)을
한 화면에 모아, 누구나 이어받아 운영할 수 있게 만든 정적 웹앱입니다.

- **대시보드:** `index.html` — 보는 화면
- **관리:** `settings.html` — 내용을 고치는 화면 (4자리 잠금)
- 서버 없이 동작하며 GitHub Pages 로 배포합니다.

배포 주소: <https://mirestar01-gif.github.io/worship-dashboard/>

---

## 폴더 구조

```
worship-dashboard/
├─ index.html            대시보드
├─ settings.html         관리 화면
├─ data/
│  └─ seed.js            ★ 기본값(배포 기준선) — window.WD_SEED = { … }
├─ assets/
│  └─ store.js           저장·불러오기·내보내기·가져오기 공통 모듈
├─ logo.png
├─ manifest.json / icon-*.png
└─ 주일_봉헌_안내_매뉴얼.pdf
```

### 데이터가 저장되는 곳

| 위치 | 무엇 | 성격 |
|---|---|---|
| `data/seed.js` (`window.WD_SEED`) | 배포 기준선 | 레포에 커밋되는 공용 값 |
| 브라우저 `localStorage['wd_data_v1']` | 이 브라우저에서 편집한 내용 | 기기마다 따로 |

로드 규칙: `localStorage` 에 저장분이 있으면 그것을, 없으면 `seed.js` 를 사용합니다.
관리 화면의 **기본값으로 초기화**는 저장분을 `wd_data_v1_backup` 으로 옮긴 뒤 기준선으로 되돌립니다.

## 내용 고치는 법

1. `settings.html` 을 열고 4자리 비밀번호 입력
2. 항목 수정 → 아래 **💾 저장하기**
3. `index.html` 을 새로고침하면 반영 (같은 브라우저에서만)

### 두 사람(위원장·부위원장)이 같은 값을 보게 하려면

편집한 내용을 배포 기준선(`data/seed.js`)에 올려두면 두 사람 모두 같은 값에서 시작합니다.

1. 관리 화면에서 **내보내기**로 백업 `.json` 파일을 받는다
2. GitHub 에서 `data/seed.js` 를 **Edit** (연필 아이콘)
3. `window.WD_SEED = ` 뒤의 `{ … }` 부분을 방금 받은 JSON 내용으로 통째로 교체하고 **Commit**
4. 1~2분 뒤 배포되면, 상대방은 관리 화면에서 **기본값으로 초기화**를 눌러 최신 기준선으로 맞춘다

> `seed.js` 는 `window.WD_SEED = {` 로 시작해서 `};` 로 끝나야 합니다. 중괄호와 끝의 세미콜론을 지우지 마세요.

## 로컬에서 확인

`data/seed.js` 는 `<script src>` 로 불러오므로 **파일을 더블클릭해도 열립니다.**
그래도 서버로 확인하고 싶으면 폴더에서:

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000/> 접속.

---

## 배포

`main` 브랜치에 push 하면 GitHub Pages 가 자동 배포합니다.
(Settings → Pages → Source: `main` / root)

## 앞으로 (재설계 로드맵)

이 버전은 **P0(기반 정리)** 입니다 — 화면·동작은 그대로, 기본값을 한 곳(`data/seed.js`)으로 모으고
저장 로직을 `assets/store.js` 로 정리했습니다.

- **P1** — 스키마 v2 전환 + `v1→v2` 자동 마이그레이션, 대시보드 리디자인(로고 감색 `#81292D` + 연한 파랑, 이번 달 포커스 카드, 인라인 달력, 예산 카드 정리, 거래처 섹션, 다크 모드)
- **P2** — 관리 화면 개선(변경 감지·이탈 경고, 거래처 통합 편집, 체크리스트↔월 연결)
- **P3** — 접근성 정리, 인쇄·인수인계 뷰(`handoff.html`), PWA 오프라인

설계 문서: 재설계안 아티팩트 참고.
