한 화면에 모아, 누구나 이어받아 운영할 수 있게 만든 정적 웹앱입니다.

## 무엇이 달라졌나

### 보는 화면

- **이번 달 포커스** — 열자마자 이번 달 주차별 일정과 이번 달에 챙길 체크리스트가 보입니다.
  (전에는 달을 고르고 "사이트 열기"를 눌러야 나왔습니다.)
  이번 달에 걸린 일이 없으면 **다음 차례**를 대신 보여줍니다.
- **인라인 달력** — 달을 누르면 그 달이 속한 줄 **바로 아래**에 주차별 일정이 펼쳐집니다.
  화면이 널뛰지 않고, 달력 위치를 잃지 않습니다.
- **거래처 섹션** — 업체를 한 곳에 모았습니다. 체크리스트에서 업체 이름을 누르면 그 카드로 이동합니다.
  거래처 카드에는 그 업체와 엮인 체크리스트가 함께 보입니다.
- **예산 카드 정리** — 총예산 · 집행 · 잔액을 한 줄에 놓고 막대 하나로 집행률을 보여줍니다.
  집행액은 총예산과 잔액에서 자동으로 계산합니다.
- **체크 상태가 남습니다** — 체크박스를 눌러두면 새로고침해도 유지되고, **해마다 따로** 쌓입니다.
  (전에는 새로고침하면 전부 풀렸습니다.)
- **다크 모드** — 오른쪽 위 ☾ / ☀ 버튼. 기기 설정을 따라가다가, 한 번 고르면 그 선택을 기억합니다.
- 로고의 감색(`#81292D`)을 주색으로, 연한 파랑을 보조색으로 맞췄습니다.

### 안쪽

- **스키마 v2 로 전환** (`assets/store.js` 의 `WD.migrate`). 기존 v1 저장분과 백업 파일은
  **열 때 자동으로 v2 로 올라옵니다.** 따로 하실 일은 없습니다.
- 같은 업체가 체크리스트 항목마다 복사돼 있던 것을 `vendors` 카탈로그로 빼고 id 로 참조합니다.
  → 그리드룸이 두 항목에 따로 저장돼 있던 것이 한 장으로 합쳐졌습니다. 이제 한 곳만 고치면 됩니다.
- 예산 금액을 문자열(`"5,120만"`)이 아니라 **숫자**로 보관합니다. 관리 화면에는 여전히
  `5,120만` 처럼 편한 대로 쓰시면 됩니다 — 읽어서 숫자로 바꿔줍니다.
- 팀 명단을 화면에 넣을 때 `<b>` 만 남기고 나머지 태그는 글자로 바꿉니다.

## 폴더 구조

```
v2/
├─ index.html            대시보드
├─ settings.html         관리 화면
├─ data/
│  └─ seed.js            ★ 기본값(배포 기준선) — window.WD_SEED = { … }
├─ assets/
│  └─ store.js           저장·불러오기·마이그레이션 공통 모듈
├─ tools/
│  ├─ build-seed.js      next/(v1) 시드 → v2 시드 변환
│  └─ test-migrate.js    마이그레이션 점검
├─ logo.png
├─ manifest.json / icon-*.png
└─ 주일_봉헌_안내_매뉴얼.pdf
```

### 데이터가 저장되는 곳

| 위치 | 무엇 | 성격 |
|---|---|---|
| `data/seed.js` (`window.WD_SEED`) | 배포 기준선 | 레포에 커밋되는 공용 값 |
| 브라우저 `localStorage['wd_data_v1']` | 이 브라우저에서 편집한 내용 | 기기마다 따로 |
| 브라우저 `localStorage['wd_check_v2']` | 체크리스트 체크 상태 (연도별) | 기기마다 따로 |
| 브라우저 `localStorage['wd_theme']` | 밝은 화면 / 어두운 화면 선택 | 기기마다 따로 |

로드 규칙: `localStorage` 에 저장분이 있으면 그것을, 없으면 `seed.js` 를 씁니다.
어느 쪽이든 읽는 순간 v2 로 맞춰집니다.

> 저장 키 이름이 `wd_data_v1` 그대로인 것은 **일부러**입니다.
> 기존 `/next/` 에서 쓰시던 저장분을 그대로 이어받기 위해서입니다.

## 내용 고치는 법

1. `settings.html` 을 열고 4자리 비밀번호 입력
2. 항목 수정 → 아래 **💾 저장하기**
3. `index.html` 을 새로고침하면 반영 (같은 브라우저에서만)

저장하지 않고 창을 닫으려 하면 붙잡습니다. 저장 안 한 변경이 있으면
저장 막대에 **"저장하지 않은 변경 있음"** 이 뜹니다.

### 거래처를 체크리스트에 연결하기

1. 관리 화면 **거래처 · 인수인계 정보** 에서 업체를 등록
2. **위원장 연간 체크리스트** 의 각 항목에서 **거래처 연결** 을 고르기
3. 같은 업체를 여러 항목에 걸어도, 정보는 거래처 카드 한 곳만 고치면 전부 반영됩니다

### 두 사람(위원장·부위원장)이 같은 값을 보게 하려면

편집한 내용을 배포 기준선(`data/seed.js`)에 올려두면 두 분 모두 같은 값에서 시작합니다.

1. 관리 화면에서 **내보내기**로 백업 `.json` 파일을 받는다
2. GitHub 에서 `v2/data/seed.js` 를 **Edit** (연필 아이콘)
3. `window.WD_SEED = ` 뒤의 `{ … }` 부분을 방금 받은 JSON 내용으로 통째로 교체하고 **Commit**
4. 1~2분 뒤 배포되면, 상대방은 관리 화면에서 **기본값으로 되돌리기** 를 눌러 최신 기준선으로 맞춘다

> `seed.js` 는 `window.WD_SEED = {` 로 시작해서 `};` 로 끝나야 합니다.
> 중괄호와 끝의 세미콜론을 지우지 마세요.

## 로컬에서 확인

`data/seed.js` 는 `<script src>` 로 불러오므로 **파일을 더블클릭해도 열립니다.**
서버로 확인하려면 레포 최상위에서:

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000/v2/> 접속.

## 점검 도구

```bash
node v2/tools/test-migrate.js
```

마이그레이션을 점검합니다. 가장 중요한 항목은 **멱등성** — 저장할 때마다
`migrate` 가 다시 도는 구조라, 여러 번 돌려도 결과가 같지 않으면 저장할수록 데이터가 상합니다.

`v1` 시드에서 `v2` 시드를 다시 만들려면:

```bash
node v2/tools/build-seed.js
```
